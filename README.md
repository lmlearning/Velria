# Velria

Velria explores **generative AI for eliciting pupil wellbeing narratives**. This repository is the public reference for the project.

## Research context

The work connects conversational AI with education and design research. For Lars Malmqvist's publication record and related work, see [Google Scholar](https://scholar.google.com/citations?user=Z86vj_MAAAAJ&hl=en).

## Repository contents

The current public repository contains project metadata and a [license](LICENSE). Application code and study data are not included here.
